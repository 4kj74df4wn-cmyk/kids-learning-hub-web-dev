ลองเรียนเหมือนผู้ใช้จริง

รอบนี้คุณกำลังช่วยเราทดสอบประสบการณ์เรียนรู้ ผลที่ได้ใช้ตรวจระบบเท่านั้น ไม่ใช่คะแนนหรือพัฒนาการของเด็ก

เส้นทางวันนี้: เช็กพื้นฐานสั้นๆ → เรียนแบบกระชับ → ลองโจทย์ใหม่ → ถ้ายังติด เราจะช่วยแกะจุดนั้น → แล้วให้ลองใหม่ด้วยตัวเองอีกครั้ง
กติกาเดียว: ตอบตามจริง ผิดได้ เดาได้ เพราะเราต้องการรู้ว่าระบบช่วยคนตอน “ยังไม่รู้” ได้ดีแค่ไหน
ข้อมูลรอบทดสอบเก็บใน browser เครื่องนี้เท่านั้น และไม่ถูกเขียนกลับ GitHub
